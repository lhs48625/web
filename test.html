컴퓨터란

컴퓨터는 논리 연산을 수행하는 기계의 총칭이다. cpu, 메인보드, 그래픽카드, 메모리 등으로 이루어져있다.

CPU(Central Processing Unit)는 중앙 처리 장치로, 컴퓨터의 두뇌 역할을 하며 프로그램의 명령을 해석하고 데이터를 연산·처리하며 시스템 전체를 제어하는 핵심 부품입니다.

메인보드는 PC가 제대로 동작하기 위해 입력장치로 들어온 정보가 처리되면서 저장장치에서 메모리로 데이터를 불러오고, 모니터나 소리 등 다른 장치로 출력할 수 있도록 부품들을 연결하는 역할을 합니다.

그래픽카드는 컴퓨터의 화면 출력을 담당하며, 그래픽 연산과 병렬 계산에 특화된 프로세서인 GPU를 포함한 하드웨어 완제품을 의미합니다.

램(RAM)은 작업 중에 발생하는 데이터를 임시로 저장하는 역할을 수행하는 메모리입니다.
